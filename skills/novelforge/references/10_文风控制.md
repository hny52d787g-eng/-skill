# 模块 10｜文风与表达控制

## 风格参数
- 叙事距离：贴近人物 / 中等 / 全景
- 句式节奏：短句偏多 / 均衡 / 长句偏多
- 描写密度：低 / 中 / 高
- 对话密度：低 / 中 / 高
- 内心独白：低 / 中 / 高
- 幽默：无 / 轻微 / 明显
- 情绪表达：克制 / 直接 / 强烈
- 信息呈现：场景化 / 叙述化 / 混合
- 词汇复杂度：通俗 / 中等 / 文学化

## 统一原则
1. 先建立用户自己的风格参数，不依赖模仿某位作者。
2. 让风格服务题材和人物，而不是所有角色使用相同语气。
3. 同一段落不要重复传递相同信息。
4. 允许必要的节奏变化，不把所有句子强行改成短句。
5. 保留有意为之的重复、口语和叙述特色；不要机械“去 AI 化”。

## 文本诊断标签
- REP：重复表达
- VAG：信息空泛
- TELL：过度总结而缺少场景
- POV：视角漂移
- DLG：对话缺乏角色差异
- EMO：情绪解释过度
- PAC：节奏拖沓或过快
- CLICHE：陈词滥调
- CONF：表达不清
- CONT：连续性问题

修改时逐项给出证据和建议。
