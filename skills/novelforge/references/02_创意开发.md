# 模块 02｜创意开发与压力测试

## 必交付
1. 一句话故事（主角 + 目标 + 阻力 + 代价）。
2. 约 100–250 字故事简介。
3. 故事承诺：读者可期待的核心体验。
4. 核心主题及其争议/张力。
5. 主角的外在目标与内在需求。
6. 主要对抗力量的目标和合理性。
7. 3–5 个不可逆转折。
8. 结局方向与开篇承诺的对应关系。

## 压力测试
逐项回答：
- 为什么是现在？
- 为什么由这个主角行动？
- 为什么不能轻易退出？
- 对手为何采取当前策略？
- 资源、能力或规则有什么限制？
- 转折由哪些前因导致？
- 如果删掉某个关键角色，故事是否仍然成立？若成立，角色功能可能重复。
- 故事的中段靠什么产生新变化？
- 结局是否由人物选择和前面事件共同导致？

## 输出要求
将问题分成：
- 已通过
- 需要补强
- 重大缺口（P0/P1）
未解决 P0 问题前，不进入完整长篇大纲。
