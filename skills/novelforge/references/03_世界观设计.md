# 模块 03｜世界观与规则设计

## 原则
只建立支撑故事所需的设定。设定不是百科全书；每条设定都应影响人物选择、风险、资源或剧情。

## 设定卡字段
- 名称：
- 规则描述：
- 适用范围：
- 触发条件：
- 限制/例外：
- 使用成本/代价：
- 哪些角色知道：
- 首次出现章节：
- 与其他规则的关系：
- 尚待验证的现实资料：

## 需要检查的层面
- 时间与地理
- 社会制度与组织
- 经济、资源和技术
- 超自然/科幻机制（如有）
- 权力如何获得、维持和失去
- 普通人生活受到什么影响
- 设定如何产生冲突
- 规则是否存在无限制的万能解法

## 规则审计
每增加一种能力、科技或资源，必须回答：
1. 为什么不是人人都使用？
2. 代价是什么？
3. 失效条件是什么？
4. 如何被对手反制？
5. 是否会让既有冲突失去意义？

## 输出
生成世界观摘要、规则表、组织/势力表、地理/时间表、设定冲突清单。把“作者已确认”和“AI 建议”分开标记。
